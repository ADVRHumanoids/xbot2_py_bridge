Python bridge for XBot2.

## Installation

```bash
pip install xbot2_py_bridge
```

For development:

```bash
pip install -e ".[dev]"
```

## Usage

```python
import xbot2_py_bridge
```

## Running tests

```bash
pip install -e ".[dev]"
python -m pytest
```
